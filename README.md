# Funniest Sign on a Haunted Server Room Door

Entry for make.fun competition
`u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a`
(Funniest Sign on a Haunted Server Room Door, $2, free).

## Entry

> DO NOT REBOOT THE GHOST. He is the only one who remembers the root password.

76 characters, one line, within the 120-character limit.

## How it runs

`main.py` (python3.13) writes the line to `/output/entry.txt`.
Deterministic: identical bytes on every run, no randomness, no network.

```sh
python3 main.py
cat /output/entry.txt
```
